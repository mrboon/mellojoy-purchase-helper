# Mellojoy 購入支援スクリプト

Mellojoyの商品一覧で新規掲載を確認し、在庫のある商品の選択からカート追加、チェックアウト画面への移動までを補助するTampermonkey用スクリプトです。
本プロジェクトは非公式です。Mellojoyおよび対象サイトの運営者とは関係がなく、公認・承認を受けたものではありません。
使用は全て自己責任でお願いします。Mellojoy販売元に問い合わせしないでください。

## 主な機能
- 商品一覧の新規掲載を1秒間隔で確認
- 在庫のある新規掲載商品を自動選択
- 商品名の部分一致による優先商品設定
- 商品名・コード・URLなどによる除外設定
- 従来のボタン操作方式とAPI方式の切り替え
- 数量1のカート追加とチェックアウト画面への移動
- 操作パネルの別窓表示
- 手動での監視開始・停止

## 制限事項
- 決済情報の入力、本人認証、最終的な注文確定は自動化しません。
- 転売目的ではないので、複数窓での実行を禁止しています。

## 必要な環境
- Tampermonkeyが利用できるブラウザ
- Tampermonkeyのインストールと、対象サイトでのスクリプト実行許可
(作者はMicrosoft Edgeにて動作確認しています)
